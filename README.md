# PartnerSpeak (робоча назва)

iOS-застосунок для стосунків. Пари зближуються, розважаються і разом проходять складні моменти, а кожен окремо вивчає, який він у стосунках.

- **Три напрями:** Разом (ритуали, емоційні ігри, побачення) · Я у стосунках (самопізнання) · Вирішуємо (конфлікти, рутина).
- **Аудиторія:** 18+, B2C, пари й соло. Ринки — США та Європа. Мови: EN, ES, PT, UK.
- **MVP:** щоденний ритуал пари, самопізнання з приватним профілем, один сценарій конфлікту, м'який стрік, безпека. Без AI.
- **Приватність:** парні відповіді відкриваються взаємно, самопізнанням людина ділиться лише за бажанням.
- **Монетизація:** freemium, одна підписка на пару.
- **Платформа:** спершу iOS, потім Android, веб — лендинг.
